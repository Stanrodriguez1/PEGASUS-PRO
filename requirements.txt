# ── System Tools (install separately via OS package manager) ─
#
#   adb    → Android Debug Bridge (REQUIRED for all features)
#
#     Windows  : https://developer.android.com/tools/releases/platform-tools
#     macOS    : brew install android-platform-tools
#     Linux    : sudo apt install adb
#     Termux   : pkg install android-tools
#
#   scrcpy → Screen mirroring (optional, NOT available in Termux)
#
#     Windows  : https://github.com/Genymobile/scrcpy/releases
#     macOS    : brew install scrcpy
#     Linux    : sudo apt install scrcpy
#
#   nmap   → Network Security Scan (optional)
#
#     Windows  : https://nmap.org/download.html
#     macOS    : brew install nmap
#     Linux    : sudo apt install nmap
#
# ── Optional: Internet tunneling (for WAN / different network) ─
#
#   ngrok  → Expose ADB port over the internet (free account)
